# Запуск Kiyomira двойным щелчком

1. Скачайте репозиторий GitHub как ZIP и распакуйте **всю папку**, не только BAT.
2. Убедитесь, что установлен Node.js **24+** и команда `node` доступна в PATH.
3. Откройте папку проекта и дважды щёлкните `Kiyomira.bat`.
4. Появится окно консоли и интерактивный чат. Введите текст и нажмите Enter. Завершение: `/выход` либо `/exit`.

BAT не требует npm, Python и Docker. Он запускает `node --run start` из корня проекта, поэтому работает при перемещении папки, в том числе в путь с пробелами и кириллицей. При ошибке окно остаётся открытым, чтобы можно было прочитать сообщение.

Пока интерфейс **консольный**, браузер не открывается: веб-интерфейса в репозитории ещё нет.

По умолчанию используется тестовая модель (не настоящий ИИ). Для Cloud.ru перед запуском установите переменные окружения `CLOUD_RU_API_KEY` и `CLOUD_RU_MODEL` для процесса или пользователя Windows. **Не записывайте ключ прямо в BAT или GitHub.**

Локальная SQLite-память хранится в `06-Данные/память.sqlite` и сохраняется между запусками. Одновременно запускайте только один экземпляр, пока нет блокировки второго запуска.

Примечание: `node --run` использует package.json (обязательное техническое имя), а пути внутри него записаны по-русски.
