# Веб-версия Kiyomira — локальный интерфейс

## Запуск
- На Windows дважды нажмите `Kiyomira.bat`: проверяются локальные Node.js/Python, источник, SQLite, затем создаётся проверенная резервная копия базы и запускается веб-сервер.
- Веб-сервер слушает **только 127.0.0.1**, выбирает свободный порт автоматически. Браузер откроется только после готовности.
- Для запуска прежнего терминального чата: `set KIYOMIRA_MODE=cli` и затем `Kiyomira.bat` в том же окне CMD. Для отключения браузера задайте `KIYOMIRA_NO_BROWSER=1`.
- Для ручного запуска из корня проекта с установленным Node.js 24.21.0: `npm run web`. В таком случае автоматическая резервная копия из BAT не запускается.
- Для выхода используйте **Настройки → Завершить программу**, либо `Ctrl+C` в консоли. Простое закрытие вкладки браузера не останавливает процесс.

## Дизайн
Адаптация переменных `styles.css` из `Aspksa/Tenmayurika`: чёрный `#000`, медный `#ee8a3c`, светлый акцент `#ffcf9a`, текст `#e9e2d6`, моноширинная системная гарнитура. Масштабируемые интервалы, тонкие границы, уголки 3 px и адаптивная навигация.

## Чаты
- **SQLite — единое локальное хранилище**, без внешних БД. Создание, переименование, удаление диалогов, загрузка истории и поиск работают на сервере.
- При первом запуске старые сообщения терминального чата переводятся в диалог **«История до веб-версии»** без удаления содержимого. Дополнительные столбцы добавляются в ту же базу, а не копируются в новую.
- Поиск охватывает до 5000 недавних сообщений (до 50 совпадений); история в одном открытом диалоге показывает последние 200 записей. Старые записи остаются в SQLite.
- Данные сгенерированного ответа и пользовательского запроса сохраняются в одной транзакции. Прерванный или неуспешный запрос пару не добавляет.
- Привычное `06-Данные/резервные-копии` остаётся. Перед веб-запуском через BAT делается проверяемая резервная копия, хранятся последние пять.

## Cloud.ru
- **Без ключа и модели чат не имитирует ответ ИИ.** Он показывает ошибку настройки и не сохраняет ложный диалог. Тестовую эхо-модель можно включить только явным флажком в настройках, она никогда не обращается к Cloud.ru.
- В настройках можно ввести API-ключ, указать модель и получить список моделей через официальный `GET https://foundation-models.api.cloud.ru/v1/models`. Модель должна быть доступна конкретному ключу Foundation Models. Проверка списка не гарантирует возможность генерации.
- Кнопка **«Проверить реальный ответ (платно)»** отдельно отправляет один короткий запрос в `POST /v1/chat/completions` с `max_tokens: 16`, только после явного подтверждения. Возможна тарификация Cloud.ru. Пробный ответ не записывается в историю диалогов.
- Ошибки HTTP 401/402/403/404/429/502/503 показываются понятными сообщениями без передачи API-ключа; при ошибке сеть не заменяется тестовым ответом.
- **Секрет никогда не передаётся обратно в браузер, не записывается в SQLite, журнал и настройки.** Ключ находится только в памяти процесса на время текущего сеанса и после перезапуска вводится снова; модель сохраняется в SQLite.
- Если нужны постоянные настройки ключа без повторного ввода, можно использовать переменную окружения `CLOUD_RU_API_KEY` только на своём ПК; `.env` не загружается автоматически и запрещён для Git.
- Настройки Cloud.ru проверяют получение списка моделей; проверка не гарантирует доступность конкретной модели для генерации и не тратит токены чата.
- Ответы пока **не потоковые**: показываются после завершения HTTP-запроса. Кнопка «Остановить» отменяет запрос до сохранения. Если ключ или модель не указаны, полноценный чат не начинается.
- Нет защиты финансового лимита Cloud.ru или резервной модели. Не отправляйте секреты через чужие VPN и прокси.

## Безопасность и ограничения
- HTTP API и страница доступны только с `127.0.0.1`, имеют одноразовую cookie-сессию, проверки `Origin`, `Host` и дополнительный заголовок запроса, запрет CORS и строгую Content Security Policy.
- Доступ другого пользователя той же ОС к локальному процессу и папке должен ограничиваться правами файловой системы Windows. Нет логинов и внешнего доступа: **не открывайте порт наружу**.
- HTML не принимает произвольный Markdown/HTML. Поддерживаются безопасные подмножества заголовков, списков, блоков кода, жирного/курсива и HTTPS/HTTP-ссылок.
- Только встроенные компоненты Node.js и браузера; нет Docker, Ollama, npm-зависимостей и новых служб.
- Тесты выполняются GitHub Actions на Windows/Linux с Node.js 24 и с Windows BAT по путям со спецсимволами. Реальный внешний M.2 и аппаратные сбои (отключение питания/выдёргивание кабеля) следует испытать отдельно, не на единственной копии важных данных.

## Требования Cloud.ru согласно официальной документации

- Создайте **сервисный аккаунт уровня «Проект»** и API-ключ, назначенный сервису **Foundation Models** в кабинете Cloud.ru (AI Factory).
- Учитывайте время действия ключа и разрешённые интервалы. Используйте значение **Key Secret**, а не ID ключа.
- Базовый URL: `https://foundation-models.api.cloud.ru/v1`.
- Для чата: `POST /v1/chat/completions`, Bearer авторизация, `model`, `messages` с `role=user/assistant` и `content`; для списка: `GET /v1/models`.
- Пример ID модели из официального быстрого старта: `ai-sage/GigaChat3-10B-A1.8B`. Доступность конкретной модели нужно проверять своим ключом, не считать пример гарантированно доступным.
- Источники: https://cloud.ru/docs/foundation-models/ug/topics/api-ref__specs , https://cloud.ru/docs/foundation-models/ug/topics/api-ref__authentication , https://cloud.ru/docs/foundation-models/ug/topics/quickstart .
