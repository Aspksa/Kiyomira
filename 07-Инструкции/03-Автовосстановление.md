# 03 — Автономный запуск и восстановление

**Node.js остаётся основным ядром.** Python 3.13.17 хранится отдельно в `09-Окружение/Пайтон` и пока не используется. Запуск — двойной клик `Kiyomira.bat`. На Windows x64 нужен встроенный PowerShell, доступ к сети только при первой загрузке или восстановлении.

## Поведение
- Проверяются права записи, критические файлы проекта и наличие Node.js.
- Runtime Node.js 24.21.0 и Python загружаются только при отсутствии или нарушении сохранённых SHA-256; повторный запуск полностью офлайн.
- Для Node.js проверяется ZIP по официальному SHASUMS256.txt, для Python — опубликованный на python.org SHA-256. После распаковки создаётся реестр SHA-256 каждого файла в runtime. Это проверка случайного повреждения; реестр на том же диске **не является криптографическим доказательством подлинности**.
- Перед переключением проверяются все файлы нового runtime, executable и версия. Старый runtime сохраняется в папке `.резерв` и автоматически восстанавливается при повреждении текущего.
- Неудачная загрузка использует 3 попытки, временная папка очищается. Старые временные папки удаляются только после 24 часов и только с префиксом `загрузка-`; `06-Данные` не трогается.
- Первый успешный запуск делает локальную резервную копию файлов загрузчика в `09-Окружение/РезервЗагрузчика`; при последующем повреждении эти файлы сверяются с SHA-256 и восстанавливаются. Если повреждены сам BAT или PowerShell bootstrap, автоматический ремонт невозможен — нужно восстановить их из GitHub вручную.
- При двух запусках создаются отдельные временная блокировка установки и блокировка работающего ядра.
- Предпроверка читает существующую базу SQLite в режиме read-only, выполняет `PRAGMA integrity_check` и **не пытается автоматически исправлять повреждённую базу**.
- Журналы автоматически ротируются примерно после 2 МБ, хранят до 3 резервных файлов. Ключи Cloud.ru не записываются явно; не передавайте секреты как параметры командной строки.
- При выходе из CLI командой `/выход` или `/exit` ядро закрывает память. Для Ctrl+C добавлен обработчик остановки.
- `09-Окружение/Библиотеки-Пайтон` — пока пустой каталог для будущих пакетов Python, без pip и автоматических установок.
- Автооткрытие браузера **отключено**, так как веб-сервер ещё не существует. Открывать браузер нужно лишь после появления реального HTTP endpoint готовности.

## Как тестировать
`npm test`, `npm run preflight`, `npm start`. В CI предусмотрены Windows/Linux тесты ядра и Windows BAT из папки со спецсимволами; Windows BAT дважды запускается офлайн с локальным Node.js. Для полного подтверждения длинных путей более 260 символов нужны включённая в Windows поддержка длинных путей и дополнительный тест на пользовательском компьютере.

## Ограничения
Это не Windows-служба, нет фонового обновлятора, перезапуска упавшего ИИ или встроенного обхода антивируса. В случае проблем загрузки см. `06-Данные/журнал-окружения.log`. Ошибки сети, файловой системы и антивируса могут пересекаться, поэтому по одному коду ошибки нельзя достоверно определить причину.
