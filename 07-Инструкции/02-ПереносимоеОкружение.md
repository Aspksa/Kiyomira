# 02 — Переносимое окружение Node.js и Python

Двойной клик по **Kiyomira.bat** в Windows. Первый запуск скачивает в папку проекта официальные ZIP-архивы Node.js 24.21.0 и Python 3.13.17 (64-битные версии), не устанавливая программы в Windows.

- `09-Окружение/Нода/node.exe` — запускает TypeScript-ядро.
- `09-Окружение/Пайтон/python.exe` — **подготавливается на будущее**, но не запускается и не подключён к ядру.
- `06-Данные` — SQLite и журналы. При переносе на M.2 копируйте **всю папку**, включая её.

### Защита
- Node.js: SHA-256 ZIP проверяется по официальному `SHASUMS256.txt` из того же HTTPS-источника nodejs.org.
- Python: SHA-256 ZIP зафиксирован по странице релиза Python 3.13.17 на python.org.
- Распаковка идёт во временную папку внутри проекта; после проверки файлы перемещаются в `09-Окружение`. Ошибка скачивания не должна оставлять наполовину установленную версию.
- Повторный запуск использует уже загруженные версии. При отсутствии интернета после установки всё запускается офлайн.
- Не используются `pip install`, глобальный PATH, системные сервисы, Docker или Python API.
- Если необязательная загрузка Python не удалась, ядро TypeScript продолжает запускаться. На следующем запуске Python скачивается повторно.
- Если локальный runtime повреждён или несовместим, обновление не выполняется вслепую: ошибка фиксируется, требуется диагностика.

### Примечания
Нужны Windows x64, PowerShell 5.1+ (входит в Windows), доступ к nodejs.org и python.org при первом запуске. При ограничениях сети автоматическая загрузка может не сработать. ZIP Python embeddable не содержит готового pip; для будущих Python-модулей понадобится отдельно согласовать зависимости и способ их установки.

Веб-интерфейса ещё нет: после подготовки среды открывается консольный чат. Без ключа Cloud.ru используется только демонстрационная модель.
