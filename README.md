# Kiyomira

Первый этап: ядро на TypeScript, без Python.

## Требования
Node.js 22.18+ (рекомендуется 24+). Встроенная поддержка запуска TypeScript (удаление типов), без npm-зависимостей.

## Запуск
```powershell
npm start
npm test
```

Все авторские папки и файлы TypeScript пронумерованы и названы по-русски. Служебный `package.json` оставлен на латинице, так как Node.js требует именно это имя.

## Возможности
- Жизненный цикл ядра и передача событий
- Память диалога с ограничением объёма (пока только оперативная память)
- Последовательная очередь фоновых задач с обработкой ошибок
- Интерфейс провайдера LLM и тестовый провайдер
- Остановка, диагностика состояния, тесты без внешних библиотек

Пока **не реализованы**: постоянная SQLite-память, RAG, личность, настоящее фоновое обучение, интерфейс, Cloud.ru-адаптер, Python. Это последовательные этапы, а не имитация готовой системы.

## Структура
- `01-Ядро/` — точка входа и управление
- `02-Память/` — записи диалога
- `03-Задачи/` — очередь фоновых операций
- `04-Модели/` — интерфейс LLM и заглушка для тестов
- `05-Проверки/` — тесты

Нумерация в имени позволяет стабильно упорядочивать папки и файлы. Кодировка UTF-8. Не используйте ANSI при работе через PowerShell.
