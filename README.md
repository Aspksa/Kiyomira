# Kiyomira — локальная веб-версия и ядро TypeScript

Рабочий TypeScript-каркас с локальной веб-версией в стиле Tenmayurika: чат, диалоги, SQLite-память, поиск и настройки Cloud.ru. Python пока **не используется**.

## Требования
Node.js **24+**. Никаких npm-зависимостей и Docker. Все имена авторских исходников на русском языке, технические файлы `package.json`, `.gitignore` и каталог `.github` сохраняют обязательные имена.

## Запуск двойным кликом на Windows

Откройте папку Kiyomira и запустите `Kiyomira.bat`. **На Windows x64 первый запуск автоматически скачает Node.js 24.21.0 и Python 3.13.17 в `09-Окружение/`** через `Kiyomira.ps1`. Python пока не используется, но будет готов для будущих возможностей. После скачивания Node.js и Python запускайте проект офлайн и переносите целую папку на M.2. **По умолчанию открывается локальная веб-страница:** браузер запускается только после готовности HTTP-сервера на 127.0.0.1 и случайном свободном порту. Закройте программу через Настройки → Завершить программу или Ctrl+C в окне BAT. Обычное закрытие вкладки не останавливает сервер. Понадобится встроенный Windows PowerShell и интернет при первой установке. Подробности: `07-Инструкции/02-ПереносимоеОкружение.md`, `07-Инструкции/03-Автовосстановление.md`, **`07-Инструкции/04-ВебИнтерфейс.md`**.

## Запуск (PowerShell)
```powershell
npm test
npm run web  # веб-версия (требует Node.js 24+)
npm start    # прежний терминальный режим
npm start -- "Как дела?"
```

Без ключа программа **явно сообщает о демо-режиме** и использует тестовую модель (не настоящий ИИ). В браузере откройте настройки Cloud.ru для ввода ключа, выбора модели и проверки подключения. Секрет остаётся только в памяти процесса; после перезапуска потребуется повторный ввод. Текст и история чатов сохраняются в локальной SQLite.

## Cloud.ru
Создайте API-ключ в Foundation Models и выберите ID модели, доступной вашему аккаунту. В PowerShell:
```powershell
$env:CLOUD_RU_API_KEY = "ВАШ_КЛЮЧ"
$env:CLOUD_RU_MODEL = "ai-sage/GigaChat3-10B-A1.8B"
npm start -- "Привет!"
```
Никогда не сохраняйте API-ключ в GitHub. Доступный ID модели может измениться; проверяйте в каталоге Cloud.ru.

API: https://foundation-models.api.cloud.ru/v1 (Bearer, OpenAI-compatible).
Один реальный запрос может тарифицироваться провайдером. Автоматические тесты **не** обращаются к Cloud.ru.

## Структура
- `01-Ядро/` — запуск, жизненный цикл, события, диагностика
- `02-Память/` — постоянное хранение сообщений SQLite, атомарная запись пары
- `03-Задачи/` — последовательная очередь работ с фиксацией ошибок
- `04-Модели/` — контракт LLM, тестовый и Cloud.ru провайдеры
- `05-Проверки/` — тесты (SQLite и поддельный HTTP для Cloud.ru)
- `06-Данные/` — локальная база и резервные копии (создаются автоматически, исключены из Git)
- `08-Запуск/` — переносимый BAT-запуск, диагностика SQLite и защищённый локальный HTTP-сервер
- `10-Веб/` — HTML, CSS и JavaScript адаптивного интерфейса Tenmayurika
- `09-Окружение/` — переносимые Node.js и Python, исключены из Git

`KIYOMIRA_DB_PATH` позволяет изменить путь к SQLite. В памяти диалога для запросов используются последние 200 сообщений; в базе сохраняется полная история, пока её явно не удалить.

## Текущее ограничение
Веб-интерфейс работает **только локально**. История SQLite сохраняется между запусками, но доступ к Cloud.ru зависит от учётной записи и модели. Ответы пока не потоковые, хотя активный облачный запрос можно отменить. Нет RAG, векторной памяти, бюджетных ограничений Cloud.ru, Python API и автономного обучения. Веб-сервер не доступен из внешней сети. Подробности и границы безопасности — в документе `07-Инструкции/04-ВебИнтерфейс.md`.
